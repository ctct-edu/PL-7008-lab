## コース全体の流れ

このコースのラボは大きく2つのグループに分かれています。

### Lab01: 独立した練習演習

**Lab01** は独立した演習です。架空の経費精算エージェントを作成して基本操作を学びますが、**Lab02 以降では使用しません**。

### Lab02〜08: 不動産予約サービスの段階的構築

**Lab02〜08** は連続しており、「Real Estate Booking Service」エージェントを段階的に構築します。前のラボの成果物を引き継いで進めてください。

| ラボ | タイトル | 主な内容 | 前提ラボ |
|------|----------|----------|----------|
| Lab02 | Dataverseソリューションのインポート | データ環境のセットアップ | なし |
| Lab03 | 初期エージェントの構築 | エージェント作成・基本設定 | Lab02 |
| Lab04 | トピックの管理 | トピックの作成・AI支援編集 | Lab03 |
| Lab05 | ノードの管理 | 会話フロー・変数・認証設定 | Lab04 |
| Lab06 | エンティティを使った作業 | カスタムエンティティ作成 | Lab05 |
| Lab07 | エージェントフローの作成 | Power Automate フロー連携 | Lab06 |
| Lab08 | 生成AIを使用する | 生成AIオーケストレーション有効化 | Lab07 |

### Lab09: Microsoft Teams へのデプロイ

> **注意:** Lab09 は Copilot Studio の**試用版ライセンスでは実施できません**。Lab09 冒頭の注記を確認してください。
